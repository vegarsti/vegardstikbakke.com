     Plan: Add Draft Content Generation for Local Development

     Objective

     Add a feature to generate draft posts during local development (make 
     serve) while excluding them from production builds (make generate).

     Current Implementation

     - Draft filtering happens at main.go:17 via filterPublished(posts)
     - filterPublished() in parser.go:156-165 removes all posts where Draft 
     == true
     - Both make serve and make generate run ./ssg with no arguments, so 
     both filter drafts
     - No existing posts have draft: true set

     Implementation Approach

     1. Add Command-Line Flag (main.go)

     Add flag parsing at the top of main():
     - Import flag package
     - Add boolean flag: -include-drafts (default: false)
     - Parse flags before loading posts

     2. Modify Draft Filtering (parser.go)

     Update filterPublished() function:
     - Add includeDrafts bool parameter
     - When includeDrafts == true, return all posts unchanged
     - When includeDrafts == false, filter as before (current behavior)

     Update call site in main.go:
     - Pass the flag value to filterPublished(posts, includeDrafts)

     3. Update Makefile Commands

     Modify the serve target:
     - Change from ./ssg to ./ssg -include-drafts
     - Keep generate target as ./ssg (no flag, excludes drafts)

     Files to Modify

     - /Users/vegard/dev/personal-site-static/main.go - Add flag parsing, 
     pass to filterPublished
     - /Users/vegard/dev/personal-site-static/parser.go - Add parameter to 
     filterPublished
     - /Users/vegard/dev/personal-site-static/Makefile - Update serve target

     Benefits

     - Simple, minimal implementation (follows project philosophy)
     - Clear separation between dev (with drafts) and production (without 
     drafts)
     - No breaking changes - default behavior remains the same
     - No new dependencies - uses standard library flag package

     Testing

     After implementation:
     1. Create a test post with draft: true
     2. Run make generate - verify draft is excluded
     3. Run make serve - verify draft is included
     4. Check both homepage and posts listing
