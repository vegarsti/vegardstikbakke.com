     Dark Mode Implementation Plan

     Overview

     Add dark mode support to the site using CSS custom properties and the 
     prefers-color-scheme media query. The implementation will automatically
      respect the user's system setting without requiring a manual toggle.

     Current State

     - All CSS is inline in templates.go (lines 18-147)
     - Current color scheme is light-only with hardcoded values:
       - Primary text: #111
       - Secondary text: #666
       - Links: #0066cc
       - Borders: #ddd
       - Code background: #f4f4f4
       - Draft badge background: #f0f0f0

     Implementation Approach

     Step 1: Define CSS Custom Properties

     Add a :root selector at the beginning of the <style> section with CSS 
     variables for all colors:

     :root {
         --bg-color: #ffffff;
         --text-color: #111;
         --text-secondary: #666;
         --link-color: #0066cc;
         --border-color: #ddd;
         --code-bg: #f4f4f4;
         --badge-bg: #f0f0f0;
         --badge-text: #666;
     }

     Step 2: Add Dark Mode Media Query

     Add a @media (prefers-color-scheme: dark) query that overrides the 
     variables:

     @media (prefers-color-scheme: dark) {
         :root {
             --bg-color: #1a1a1a;
             --text-color: #e4e4e4;
             --text-secondary: #a0a0a0;
             --link-color: #66b3ff;
             --border-color: #404040;
             --code-bg: #2d2d2d;
             --badge-bg: #333;
             --badge-text: #999;
         }
     }

     Step 3: Update All Color References

     Replace all hardcoded color values in the CSS to use the custom 
     properties:

     - body: Add background-color: var(--bg-color); and change color: #111 
     to color: var(--text-color)
     - nav: Change border-bottom: 1px solid #ddd to use var(--border-color)
     - nav a: Change color: #111 to color: var(--text-color)
     - .post-title a: Change color: #111 to color: var(--text-color)
     - .post-date: Change color: #666 to color: var(--text-secondary)
     - .draft-badge: Update both background and color to use variables
     - .book-title a: Change color: #333 to color: var(--text-color)
     - .book-author, .book-date, .book-rating: Update to use appropriate 
     variables
     - pre: Change background: #f4f4f4 to background: var(--code-bg)
     - a: Change color: #0066cc to color: var(--link-color)

     Files to Modify

     - templates.go (lines 18-147 in the <style> section)

     Benefits

     - Automatic dark mode based on system preference
     - No JavaScript required
     - Easy to maintain - colors defined in one place
     - Follows modern web standards
     - Better for users' eyes in low-light conditions

     Testing

     After implementation:
     1. Run make serve to build and serve the site
     2. Test with system in light mode
     3. Test with system in dark mode (System Preferences > Appearance)
     4. Verify all elements (text, links, code blocks, navigation, borders) 
     render correctly in both modes
